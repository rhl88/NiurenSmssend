# CmsPro 牛人短信 · 使用指南

> 版本：1.0.0 | 更新日期：2026-10-22
> 应用版本：1.0.4 | 应用 ID：niuren.smssend

本指南面向后台管理员，说明「短信发送」应用的安装、服务商配置、模板字段搭配、短信发送与记录查询的完整使用流程。

---

## 一、环境要求

| 项目 | 要求 |
|------|------|
| PHP | `>= 8.3` |
| CmsPro | `>= 5.0.0` |
| 扩展 | 需启用 `curl`、`json`、`openssl`、`hash`（腾讯云 TC3 签名依赖 HMAC-SHA256） |
| 数据库 | MySQL 5.7+ / 8.0（SQLite 亦可用于测试） |
| 其他 | 阿里云 / 腾讯云短信账号已开通短信服务，且模板已审核通过 |

---

## 二、安装与启用

1. 将应用目录 `app/Apps/NiurenSmssend/` 放入站点。
2. 在后台「应用管理」中安装应用。安装过程会自动：
   - 执行 3 个迁移，创建 `templates` / `template_fields` / `records` 三张表；
   - 依据 `manifest.json` 写入 4 个配置组（共 18 项默认配置）；
   - 注册 4 个子菜单与 4 个权限点。
3. 安装后启用应用，并到「角色 / 权限」中为相应角色勾选权限：
   - `niuren.smssend.setting`（短信设置）
   - `niuren.smssend.template`（短信模板管理）
   - `niuren.smssend.send`（发送短信）
   - `niuren.smssend.record`（发送记录）

启用后，后台左侧菜单会新增一级菜单「短信发送」。

## 三、功能验证（页面入口）

| 页面 | 访问路径 | 说明 |
|------|----------|------|
| 发送短信 | `/admin/niuren/smssend/send` | 选择模板、填写表单并发送 |
| 短信模板 | `/admin/niuren/smssend/templates` | 模板与变量字段的增删改查 |
| 发送记录 | `/admin/niuren/smssend/records` | 发送记录检索与详情 |

依次打开上述页面，均可正常渲染即安装成功。

## 四、第一步：配置短信服务商

进入「短信发送 → 短信设置」。

### 1. 选择当前启用服务商

页面顶部「当前启用服务商」下拉可选：

| 取值 | 服务商 | 状态 |
|------|--------|------|
| `aliyun` | 阿里云 | 完整支持 |
| `tencent` | 腾讯云 | 完整支持 |
| `volcano` | 火山引擎 | 预留（暂不可实际发送） |

> 说明：该选项用于「新建模板时的默认服务商」以及发送页的默认提示。**实际发送时以模板自身所属的服务商配置为准**（模板在新建时需绑定服务商）。

### 2. 阿里云配置项

| 配置项 | 说明 |
|--------|------|
| AccessKey ID | 阿里云 RAM 用户 AccessKey ID |
| AccessKey Secret | 阿里云 AccessKey Secret（用于 HMAC-SHA1 签名；**留空则保持原值**） |
| 短信签名 | 控制台审核通过的签名名称，如「牛人体检」 |
| 地域 RegionId | 默认 `cn-hangzhou` |
| 接口地址 Endpoint | 默认 `dysmsapi.aliyuncs.com` |

### 3. 腾讯云配置项

| 配置项 | 说明 |
|--------|------|
| SecretId | 腾讯云访问密钥 SecretId |
| SecretKey | 腾讯云访问密钥 SecretKey（用于 TC3 签名；**留空则保持原值**） |
| 短信应用 SdkAppId | 短信控制台应用 ID，如 `1400xxxxxx` |
| 短信签名 | 签名内容（不含【】符号） |
| 地域 Region | 默认 `ap-guangzhou` |
| 接口地址 Endpoint | 默认 `sms.tencentcloudapi.com` |

### 4. 火山引擎配置项（预留）

| 配置项 | 说明 |
|--------|------|
| AccessKey | 火山引擎 AccessKey ID |
| SecretKey | 火山引擎 Secret Access Key（**留空则保持原值**） |
| 短信签名 | 审核通过的签名 |
| 短信服务账号 | 短信服务 `SmsAccount` |
| 地域 Region | 默认 `cn-north-1` |
| 接口地址 Endpoint | 默认 `sms.volcengineapi.com` |

填写完对应服务商参数后点击「保存」。为保障安全，`AccessKey Secret` / `SecretKey` 留空表示「不修改」，不会清空已保存的值。

> **密钥存储策略与确认记录**
> `AccessKey Secret` / `SecretKey` 采用**明文存储 + 表单明文回显**：密钥明文写入 `config_items` 表，设置页读取时明文返回以填充表单，编辑时留空即保持原值。
> 该策略已由应用所有者于 2026-10-22 在应用验收环节明确确认采用。请务必妥善保护数据库与备份文件，避免密钥泄露；若后续安全要求提升，可改为加密存储或掩码回显方案。

## 五、第二步：创建短信模板与变量字段

进入「短信发送 → 短信模板」，点击「新建模板」。

### 1. 模板基础信息

| 项目 | 说明 |
|------|------|
| 模板名称 | 便于识别的名称，如「体检通知」 |
| 模板 CODE | 服务商控制台审核通过的模板编码，如 `SMS_512651836` |
| 模板标识 | 选填；应用级唯一标识，供其他应用按标识调用，详见下文说明 |
| 服务商 | 该模板所属服务商（同服务商下 CODE 唯一） |
| 短信签名 | 可留空，留空时使用服务商配置中的默认签名 |
| 模板内容 | 含 `${变量名}` 占位符的短信正文 |
| 状态 | 启用 / 停用（停用后不可用于发送） |
| 备注 | 可选说明 |

### 2. 模板标识

「模板标识」为选填项，用于给模板设置一个**应用级唯一标识**（区别于服务商侧的模板 CODE），供其他应用按标识调用发送服务，不依赖模板自增 ID。

- **选填**：留空保存后，模板仅供按 ID 调用；
- **全局唯一**：跨服务商不允许重复，保存时校验，重复将提示「模板标识已被使用」；
- **格式**：2–100 位，以字母或数字开头，允许包含点（`.`）、中划线（`-`）、下划线（`_`），如 `user.register.verify`。

### 3. 模板内容示例

以体检通知模板（CODE：`SMS_512651836`）为例，模板内容填写：

```
尊敬的${name}，您好!您本次体检${type}，结果${info}。医嘱${note}如有疑问，可于工作时间致电020-87430233了解详情或预约门诊。祝您健康!
```

### 4. 搭配变量字段（表单控件）

在模板内容下方点击「解析变量」，系统会自动识别出 `name`、`type`、`info`、`note` 四个变量并生成字段组；也可「手动添加变量」。

每个变量可搭配**一个或多个控件**，多个控件按排序顺序拼接为该变量的最终值。以本示例为例可搭配为：

| 变量 | 控件类型 | 字段名称 | 说明 |
|------|----------|----------|------|
| `${name}` | 单行文本 + 单选 | 姓名 / 性别 | 姓名文本与性别单选拼接，如「张三男」 |
| `${type}` | 单选下拉 | 类型 | 如体检类型 |
| `${info}` | 多行文本 | 结果 | 体检结果 |
| `${note}` | 多行文本 | 备注 | 医嘱备注 |

### 5. 控件与选项说明

支持的控件类型：单行文本、多行文本、单选、单选下拉、数字、日期、多选、手机号。

- 选项类控件（单选 / 单选下拉 / 多选）需在「选项」文本框中配置，**每行一个**，支持 `标签=值` 写法（如 `男=male`），至少配置一项。
- 可设置默认值与输入提示，并勾选是否必填。

配置完字段后点击保存，模板即创建完成。

## 六、第三步：发送短信

进入「短信发送 → 发送短信」。

1. **填写接收手机号**：支持国际号码，可带 `+` 前缀；单次发送一个手机号。
2. **选择短信模板**：下拉仅列出启用状态的模板，格式为「模板名称（CODE · 服务商）」。
3. 选择后页面展示模板信息（名称 / CODE / 服务商 / 签名 / 内容）。
4. **填写模板表单**：按上一步配置的控件渲染动态表单，必填项带 `*` 标记。
5. **查看短信预览**：页面实时按变量顺序拼接并展示最终短信内容（实际以服务商模板渲染为准）。
6. 点击「立即发送」。

发送结果：
- **成功**：弹出结果窗口，展示手机号、模板名称 / CODE、服务商、发送状态、服务商回执与短信内容。
- **失败**：页面右上角提示失败原因（如模板未审核、余额不足、手机号在黑名单等）。

---

## 七、第四步：查看发送记录

进入「短信发送 → 发送记录」。

- **检索条件**：服务商、发送状态（待发送 / 发送成功 / 发送失败）、关键字（手机号 / 模板名称 / 模板 CODE / 调用来源）、日期范围。
- **列表字段**：手机号、模板名称、模板 CODE、调用来源、服务商、短信内容、发送状态、服务商回执、发送时间。
- **调用来源**：发起本次发送的应用标识，由调用方应用在调用发送服务时传入；显示「后台」徽章表示后台手动发送。
- **详情**：点击行内「详情」，可查看基本信息（含调用来源）、短信内容、发送参数、失败原因、服务商原始响应以及接口信息（发送时调用的接口地址、请求方式与请求数据，用于排查请求是否发出、发到了哪个接口）。

发送记录为只读数据，不提供编辑与删除，以保证审计与追溯。

## 八、卸载验证

在后台「应用管理」中卸载应用，卸载将：
1. 回滚 3 个迁移，删除 `templates` / `template_fields` / `records` 三张表；
2. 清理 18 个配置项及对应缓存；
3. 移除菜单与权限点。

卸载后，后台菜单不再出现「短信发送」，应用页面不可访问。

## 九、常见问题

| 现象 | 可能原因 | 处理方式 |
|------|----------|----------|
| 页面提示「登录已过期，请重新登录」 | 后台登录态失效 | 重新登录后台 |
| 打开页面提示无权限 | 当前角色未勾选对应权限 | 在「角色 / 权限」中补授权限 |
| 发送失败：短信模板不存在或未审核通过 | 模板 CODE 与服务商控制台不一致或未审核 | 核对模板 CODE 与审核状态 |
| 发送失败：账户余额不足 | 服务商账户欠费 | 到服务商控制台充值 |
| 发送失败：手机号在腾讯云黑名单中 | 号码命中服务商黑名单 | 联系服务商处理或更换号码 |
| 发送失败：短信服务未完成配置 | 对应服务商 AccessKey 等参数未填 | 到「短信设置」补全对应服务商配置 |
| 选择火山引擎发送被拒绝 | 火山引擎为预留能力 | 改用阿里云或腾讯云 |
| 保存设置后发现密钥被清空 | 误以为留空会清空 | 留空表示「不修改」，如需更换请重新填写完整值 |
| 变量未替换成预期内容 | 同一变量配置了多个控件 | 多个控件会按排序顺序无分隔符拼接，请调整控件排序 |
| 发送失败：网络连接异常（含 cURL error 28 / 6 等） | 服务器无法解析或连接服务商接口地址（DNS / 出网策略受限） | 检查服务器 DNS 解析与出网策略，确认服务商接口地址可访问 |
| 发送失败：网络连接异常（cURL error 60 / 77） | 服务器 PHP 缺少可用 CA 证书或 php.ini 的 `curl.cainfo` 路径无效 | 到「短信设置 → SSL 证书安全」点击「下载CA证书」（自动填入路径并保存）后重试；也可检查服务器 php.ini 的 `curl.cainfo` 配置 |
